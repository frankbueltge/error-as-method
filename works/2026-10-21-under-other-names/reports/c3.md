I made "The Liquid Interval", a still image drawn on a canvas at /tmp/claude-0/-home-user/16de26dc-7be7-58e5-ae68-4f47eb7776cd/scratchpad/s145/rooms/c3/index.html. It shows the temperature range in which each of the 118 elements is a liquid.

Each element gets one column, in order of atomic number, on a logarithmic Kelvin scale. A faint stem runs up to the melting point to show where the element is solid. From the melting point to the boiling point there is a bar in the element's CPK colour, and nothing is drawn above that, where it is a gas. The table's gaps are drawn too:
- **Arsenic:** its boiling point is lower than its melting point, so it is a small cross.
- **Elements with a melting point but no boiling point:** the bar fades upward.
- **Rutherfordium (104) to oganesson (118):** they have neither value, so each is a dotted empty column.

A dotted line marks room temperature (293 K). The page works out from the data which elements are liquid there, and the caption it writes names only bromine and mercury.

Every value is read from `ELEMENTS` when the page runs, and nothing is loaded from outside the folder. The viewer rendered it with no page errors; the last check is renders/04.png.
