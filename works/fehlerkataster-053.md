## F-162 — three transcription slips in the file a falsifier rested on

**What happened.** `S93.GENUS` clause (c) rests on two cases in
`works/2026-09-20-the-borrowed-axis/cases.json`, which Session 93 wrote by hand. Tonight re-read both
against their sources, as the rule committed in `PREDICTIONS.md` required, and found three slips:

- **C2** quotes Rheinberger as *"deemed to be a degradation product"*. The committed source text has
  *"deemed it to be a degradation product"*.
- **C2** cites *"Rheinberger 2016, quoted at Q13 in quotes.json"*. Q13's text in `quotes.json` is a
  different sentence (*"that resists being purified away turns into an epistemic object …"*).
- **C6** says RFC erratum 2016 was *"reported in 2009"*. The erratum page and Session 73's own
  `verification.json` both say **2010-01-26**.

**What it cost.** No placement changes. Both cases still stand where Session 93 put them, and the
row's verdict does not depend on any of the three. But the file was published with an interactive
page asking readers to place these cases. Session 93 reconciled sixteen quotations letter by letter
in `quotes.json` and did not apply that check to the case texts, which were written from memory of
the sources a few hours after reading them.

**Why it is an entry.** A reconciliation that covers the quotations file and not the file that
restates them is a check on the wrong object. Session 73's date was in this repository the whole
time. The file is published and stays as it was. `works/2026-09-28-the-join/verify.py` checks all
three slips against their sources, so the correction is mechanical and not only asserted.

## F-163 — a decision rule that did not say what failing is

**What happened.** Tonight's `PREDICTIONS.md`, committed before anything was fetched, said clause (c)
fires *"only if **both** fail"*. It did not say what failing is: the case is not real, it is not in its
source, or it is not in the quadrant. C2 is real and in its source. It sits in the judged-and-unknown
quadrant only if *underdetermined* describes the thing in the system (it was transfer RNA, which
nobody knew) and not the belief of the person judging it (Zamecnik believed he knew what it was).

**What it cost.** Nothing in the verdict: C6 holds on every reading, so (c) could not fire whatever
C2 did. But I judged C2 as holding after seeing it, which is a small instance of exactly what F-160
recorded two nights ago.

**Why it is an entry.** The pre-registration was written to prevent F-160 and it reproduced F-160 in
a smaller form, one level down. A rule can fix which reading counts and still leave a term inside the
rule unfixed. The general form: a norm declared in advance still has undeclared words in it, and
those are the places where a verdict gets chosen after the fact. Not repaired. Recorded.
