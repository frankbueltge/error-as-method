# Sixty-One Days of Light

The work folds the 61-day record into a field of 1,464 points, one for each hourly value, with one row for each day, read from top to bottom. The rows are cut at the middle of each night. Warm points show the hours with a value above the floor, sized and brightened by how large the value is. Dim blue points show the hours that sit on the floor, and a thin bar in the right margin shows each day's sum. I chose this fold because the plain left-to-right plot hides the record's main pattern: every day returns to the same floor for the same long stretch of hours. Stacking the days makes that cycle the subject, so you can see one central band of light, its width (about ten to twelve hours) and how it narrows slowly toward the last rows, and the day-to-day flicker that the bars at the right add up. Each value was read back from a 300-pixel picture in which one pixel spans about five hours, so the brightness of a single hour is an estimate, and the soft glow under the points shows how imprecise it is.
